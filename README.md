# PDX Mod Studio

Paradox Interactive社のゲーム用MOD開発を強力にサポートする、オールインワンのデスクトップアプリケーションです。

## 🚀 主な機能
- **直感的なUI**: PySide6によるモダンで使いやすいインターフェース。
- **バリデーションエンジン**: スクリプトの構文エラーをリアルタイムで検出。
- **依存関係グラフ**: MOD間の複雑な依存関係を可視化。
- **プラグインシステム**: 機能を自由に追加・拡張可能。

## 🛠 セットアップ
1. リポジトリをクローン:
   ```bash
   git clone [URL]
   ```
2. 依存関係のインストール:
   ```bash
   pip install -r requirements.txt
   # または
   pip install .
   ```
3. アプリケーションの実行:
   ```bash
   python main.py
   ```
